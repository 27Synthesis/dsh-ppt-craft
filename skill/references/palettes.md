# 另外三套配色（同一套结构，换令牌不换做法）

一套 deck 的骨架不变：纸底 → 卡片 → 次级面 → 强调整色 → 墨色。只换色值就能换气质。下面三套都按 `ppt_polish` 的参数写好，直接抄进调用里。

## A. 暖纸赭红（默认，讲义 / 人文课）

```json
{
  "card_fills": ["FFFCF5", "EFE7D8", "E7DCC6"],
  "border": {"FFFCF5": "EAE1D1", "EFE7D8": "DED3BE"},
  "accent_fills": ["B0472C"],
  "shadow": {"blur": 9, "dist": 3, "alpha": 17, "color": "2B2A26"}
}
```

底 `F7F2E8`，墨 `2B2A26`，辅助 `6B6459`。暖、稳、不刺眼，投影仪友好。

## B. 瑞士国际（汇报 / 数据 / 发布会）

```json
{
  "card_fills": ["FFFFFF", "F0F0EE", "E8E8E6"],
  "border": {"FFFFFF": "D4D4D2", "F0F0EE": "CFCFCD"},
  "accent_fills": ["002FA7"],
  "shadow": {"blur": 6, "dist": 2, "alpha": 12, "color": "0A0A0A"}
}
```

底 `FAFAF8`（近白），墨 `0A0A0A`，次要文字 `525252`，强调整块只用一个 IKB 蓝 `002FA7`（亮版 `5B7BFF`、深版 `001D6B`）。
规矩：圆角归零或 4px；靠**网格和留白**分层，不靠阴影；数字用等宽字体、字号拉开两档；一张图占满半版。

替代强调：柠檬 `C5E803`（活泼）、安全橙 `FF6B35`（警示）——一套只用一种。

## C. 电子杂志（品牌 / 长文导读 / 文化类）

```json
{
  "card_fills": ["F7F5F0", "EDEAE3", "E3DFD6"],
  "border": {"F7F5F0": "D8D4CB", "EDEAE3": "CFCABF"},
  "accent_fills": ["111111"],
  "shadow": {"blur": 12, "dist": 4, "alpha": 15, "color": "0A0A0B"}
}
```

底 `F1EFEA`，纸面 `F7F5F0`，墨 `0A0A0B`，分隔线 `B7B5B2`（弱）/ `7E7D7B`（强）。
规矩：衬线标题（Noto Serif SC / Playfair），正文无衬线；强调靠**字号与留白**，不靠颜色；一张大图出血，图注排在图下方一档小字；圆角 6–14px。

## 选哪套

| 场合 | 选 |
| --- | --- |
| 讲课、导学、读书会 | A |
| 汇报、评审、数据多、要显得利落 | B |
| 品牌提案、文章导读、展览 | C |

混用必坏：别在 A 的暖纸底上放 IKB 蓝大色块。换风格就整套换（底、面、边、阴影四个一起改）。

## 阴影随风格调

| 风格 | blur | dist | alpha |
| --- | --- | --- | --- |
| A 暖纸 | 9 | 3 | 17% |
| B 瑞士 | 6 | 2 | 12%（几乎平的，靠网格） |
| C 杂志 | 12 | 4 | 15%（更软） |

瑞士风如果卡片本身有描边、又在网格里对齐，可以把阴影 alpha 降到 8% 甚至 0——立体感交给留白。
