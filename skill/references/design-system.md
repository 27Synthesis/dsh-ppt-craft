# 设计默认值（直接抄，别重新发明）

一套配色 + 一套阴影 + 一套间距，贯穿全篇。换风格时整组换，别零散改。

## 配色：暖纸 + 赭红

| 用途 | 值 | 说明 |
| --- | --- | --- |
| 页面底色 | `F7F2E8` | 米白纸感，比纯白柔和，投影仪上不刺眼 |
| 卡片主面 | `FFFCF5` | 比底色亮一点，像纸片放在纸上 |
| 次级面 | `EFE7D8` | 分区、表头、引用块 |
| 三级面 | `E7DCC6` | 更深一档的沙色 |
| 强调（仅少量） | `B0472C` | 赭红，用于结论、当前节点、关键数字 |
| 正文墨色 | `2B2A26` | 不用纯黑 |
| 辅助文字 | `6B6459` | 注释、来源、页码 |

规矩：

- 一页**最多一处**强调色大面积使用；剩下的强调靠字重和字号。
- 次级面**不要用灰**（`F6F3EE` 这类浅灰最危险，和纸底糊在一起），要用比底色深两档的暖沙 `EAE0CC`，描边 `D8CBB2`。
- 深色封面可用 `2B2A26` 底 + `F7F2E8` 字，其余页保持亮底。

## 卡片

```
填充  FFFCF5
描边  EAE1D1  0.75pt
阴影  blur 9pt / dist 3pt / dir 5400000(朝下) / alpha 17% / color 2B2A26
圆角  统一 rounding（同层级同一个值）
```

- 强调卡（赭红）：阴影加重到 `blur 13 / dist 3.2 / alpha 22`，**不加描边**（描边会脏）。
- 米沙卡：描边 `DED3BE`。
- 细条（高 < 0.55"）、小标签（宽 < 0.9"）、整页背景：**跳过**，它们不需要阴影。
- 白卡压白底 = 不存在。要么换色，要么靠描边 + 阴影分层。

## 版心与字号

- 16:9 版心：左右留 0.55"，上 0.45"，下 0.5"
- 页标题 26–30pt（粗），副标 14pt，正文 12–13pt，注释 9–10pt
- 行距 1.25–1.35；段落间 6pt
- 一页最多 3 个视觉块；正文行宽不超过版心 2/3
- 页码右下角，10pt，`6B6459`

## 标题页

- 大图满版 `face.png` 压满 13.33×7.5，上覆一层 `2B2A26` + `alpha 35%` 的遮罩，标题压在左侧 1/3
- 主标题 40–44pt，副标题 16pt，底下一条 0.04" 的赭红细线（宽 1.2"）

## 目录 / 地图页

- 3–5 个编号块横向排开：序号（赭红，大）+ 标题 + 一句 8 字以内的说明
- 序号所在的位置在后续每页页眉复现，让人知道现在走到哪

## 对比表

- 表头用次级面 `EFE7D8`，行隔色（`FFFCF5` / 白交替太跳，用 `FFFCF5` / `F7F2E8`）
- 表内不留竖线，只留 0.02" 的横细线，色 `E3D9C6`
- 结论行单独提出做成卡，不要塞在表里

## 视频 / 图

- 视频卡外框与其他卡同材质，宽高比 = 素材真实比例（1280×592 → 2.16:1），给 poster 静帧
- 图片宁可裁切不要拉伸；满版图压暗到 35% 再加字

## 动画默认节奏

| 效果 | 时长 | 说明 |
| --- | --- | --- |
| fade | 450ms | 卡片、文本组 |
| wipe | 600ms（箭头）/ 420ms（表行）/ 700ms（下划线） | 方向跟着逻辑走 |
| pulse | 500ms，scale 1.07 | 强调当前，同组 delay 400 |
| hide | 200–250ms | 换内容前收掉旧的 |
| 切换 | `<p:fade spd="med"/>` 全篇统一 | 不分页搞花活 |

一页最多两次点击；超过说明内容该拆页。
